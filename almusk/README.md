# Al Musk: учёт смены парфюмерного магазина

Веб приложение для ежедневного учёта магазина Al Musk. Работает с телефона, данные общие для всех устройств. Правила учёта описаны в [PROMPT.md](PROMPT.md).

## Два входа

| | Продавец | Руководитель |
|---|---|---|
| Вход | Общий PIN продавцов, задаёт руководитель в Справочнике | `OWNER_PIN` в Vercel |
| Видит | Только текущую смену: продажи, цены продажи, выручку по способам оплаты, свои расходы из кассы | Всё |
| Не видит | Себестоимость, прибыль, закупочные цены, остатки Kaspi и переводов, зарплаты, личные операции, отчёты, расхождения, прошлые дни | |
| Открытие смены | Выбирает себя из списка, пересчитывает кассу. Зарплата из справочника, остатки Kaspi подставляются с прошлой смены как неподтверждённые | Подтверждает остатки |
| Конец смены | «Сдать смену»: фото терминала, суммы, пересчёт наличных вслепую, без расчётной суммы | Проверяет, вносит комиссию и остатки, закрывает или возвращает продавцу |
| Новый аромат | Продажа сохраняется, себестоимость ждёт цены | Вносит цену, кнопка «Заполнить из справочника» пересчитывает позиции |

Ограничения продавца проверяет сервер: закрытые данные не уходят на его телефон вообще.

**Кабинет руководителя:** сегодняшняя смена, список «Требует внимания» (сданные и незакрытые смены, позиции без себестоимости, неподтверждённые остатки, расхождения, удаления продаж продавцом, невыплаченная зарплата, пропущенная комиссия), итоги месяца, деньги, рейтинг продавцов, топ ароматов. У каждой смены есть журнал: кто, что и когда менял, удалённые продажи с причинами.

**Руководитель в смене:** в Справочнике укажите своё имя. Кнопка «Я на смене» добавляет вас в смену без зарплаты, ваши продажи считаются отдельно. Продавец тоже видит вас в списке при открытии смены.

**Общий телефон магазина:** при входе руководителя без галочки «Запомнить» PIN не сохраняется на устройстве, а вход сбрасывается через 15 минут без действий.

**Справочник ароматов:** стартовый список (209 позиций) загружается при первом запуске. Новые ароматы добавляются строкой прямо на странице или списком. При смене цены можно выбрать: «цена изменилась» (прошлые продажи не меняются) или «цена была неправильной» (себестоимость продаж пересчитывается с выбранной даты, запись в журнале смены).

## Что умеет

| Раздел | Что делает |
|---|---|
| Смена | Карточка открытия: продавцы, зарплата каждого, начальные остатки наличных, Kaspi Pay и счёта переводов, невыясненные расхождения прошлых дней |
| Продажа | Каждая позиция отдельно: духи, масло, товар. Объём, концентрация, масло и основа в мл, цена до скидки, фактическая цена, себестоимость, прибыль. Акция 2+1 с подарком. Оплата Kaspi Pay, переводом, наличными или частями |
| Операции | Расходы бизнеса, закупки товара, личные расходы владельца, перемещения между счетами, поступления, возвраты |
| Зарплата | Начислена или выплачена, с какого счёта и когда |
| Закрытие | 10 пунктов из промта: фото сверки терминала, суммы по способам оплаты, пересчёт наличных, комиссия, факт остатков. Расчёт против факта по каждому счёту |
| Отчёты | Отчёт за день в формате промта (копировать, отправить в WhatsApp), неделя, месяц, любой период: результат, деньги, рейтинг продавцов, топ ароматов |
| Расхождения | Список всех расхождений с отметкой «выяснено» и комментарием. Цифры не исправляются автоматически |
| Справочник | Ароматы и цены за 1 мл с историей изменений, импорт списком, товары, флаконы, концентрации, цена основы |

## Защита данных

* Закупочную цену, концентрацию, зарплату и способ оплаты приложение не придумывает: без них продажа не сохранится.
* Себестоимость фиксируется в момент продажи. Новая цена в справочнике не меняет прошлые продажи.
* Удаление продажи или операции требует причины и сохраняется в журнале дня.
* Закрытую смену нельзя менять. Её можно открыть для исправления, указав причину.
* Смена не закрывается без обязательных данных, если явно не подтвердить закрытие с пропусками.
* Два телефона не затрут данные друг друга: запись идёт с проверкой версии.

## Деплой на Vercel

1. vercel.com → Add New → Project → Import репозитория `checklist_bot`.
2. **Root Directory: `almusk`**. Framework Preset: Other. Deploy.
3. В проекте: Storage → Create Database → Upstash for Redis → Free → Connect to project. Vercel сам добавит `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
4. Settings → Environment Variables → `OWNER_PIN` = PIN руководителя (лучше 6 цифр и больше).
5. Deployments → три точки у последнего деплоя → Redeploy.
6. Войдите с PIN руководителя → Справочник: добавьте продавцов с зарплатой за смену и задайте PIN продавцов.

Проверка: `https://<проект>.vercel.app/api/health` должен вернуть `"store":"upstash","auth":true`. Если `memory`, база не подключена и данные не сохраняются: приложение покажет красную плашку.

Бесплатного плана Upstash хватает с запасом: одна смена это около 30 запросов на запись.

## Локальный запуск

```bash
cd almusk
npm install
npm start
```

Откройте http://localhost:3000. Данные сохраняются в `almusk/data/almusk.json`.

Тесты: `npm test` (формулы из промта, полный цикл смены через API, хранилище Upstash).
